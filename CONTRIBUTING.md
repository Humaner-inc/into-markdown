# Contributing

1. Read [`SPEC.md`](./SPEC.md)
2. Keep changes in `src/` unless you are updating docs or `eng/`
3. Run `npm run validate && npm run build` before opening a PR
4. Target `main`

## Scope

This package is the crawl library only. UI, brandingof https://markdown.humaner.io belong to Humaner.
You can run the crawler locally or create your own UI environment.
